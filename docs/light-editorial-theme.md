# 默认浅色编辑主题

日期：2026-08-16

状态：已实现；完整视觉、导出与浏览器回归通过

## 用户故事

作为用折页直接生成小红书长图的作者，我希望默认页面以白底、浅色标注和清晰文字为主，从而不需要先修改深色品牌块，就能得到适合图文阅读的发布图。

## 验收标准

- 不改变 Markdown、分页算法、1080×1440 画布、图片顺序或导出流程。
- 工作台、编辑器、文章预览和导出 PNG 使用同一套浅色语义 token。
- 文章画布与 PNG 导出背景均为纯白 `#ffffff`，正文与纸张的 WCAG 对比度不低于 4.5:1。
- 文章强调色收敛为雾粉；代码块仍能被识别，但不再是黑底。
- 白底信息图不添加默认边框或衬底，与文章画布无缝衔接。
- 真实 AI 工程文章仍为 10 页，图片 7/7，浏览器控制台错误为 0。

## 主题定义

- 纸张与 PNG 导出背景：`#ffffff`
- 正文：`#4a4843`
- 标题：`#34312e`
- 雾粉：`#e8a095`
- 雾粉浅底：`#f8e3df`
- 工作台浅灰：`#ebe5de`
- 状态栏：`#eee8e1` / `#6d665f`

正文与纸张的计算对比度约为 `9.13:1`。浅色状态栏文字与底色约为 `4.65:1`。
