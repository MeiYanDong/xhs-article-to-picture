# 默认浅色编辑主题

日期：2026-08-16

状态：已实现；本地视觉与浏览器回归通过

## 用户故事

作为用折页直接生成小红书长图的作者，我希望默认页面以白底、浅色标注和清晰文字为主，从而不需要先修改深色品牌块，就能得到适合图文阅读的发布图。

## 验收标准

- 不改变 Markdown、分页算法、1080×1440 画布、图片顺序或导出流程。
- 工作台、编辑器、文章预览和导出 PNG 使用同一套浅色语义 token。
- 文章纸张为近白色，正文与纸张的 WCAG 对比度不低于 4.5:1。
- 默认大面积深色块改为雾粉、浅杏或暖灰；代码块仍能被识别，但不再是黑底。
- 真实 AI 工程文章仍为 10 页，图片 7/7，浏览器控制台错误为 0。

## 主题定义

- 纸张：`#fffdf9`
- 正文：`#4a4843`
- 标题：`#34312e`
- 雾粉：`#e8a095`
- 浅杏：`#f3d7a6`
- 工作台浅灰：`#ebe5de`
- 状态栏：`#eee8e1` / `#6d665f`

正文与纸张的计算对比度约为 `9.2:1`。浅色状态栏文字与底色约为 `4.65:1`。

- 真实文章视觉读回：`06-xhs/fold-preview/01-light.png`、`02-light.png`、`03-light.png`，均为 1080×1440 PNG。
